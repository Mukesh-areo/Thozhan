# Android demonstration guide

The current app is a responsive website, not an APK.

1. Open the hosted demo in Chrome and sign in if its private hosting gate appears.
2. Choose Book a ride and select different Chennai pickup/drop locations.
3. Select Thozhan Auto, Mini or Sedan, inspect the illustrative fare and book.
4. Note the passenger's displayed demo OTP.
5. Switch to Driver workspace, accept the request and mark arrived.
6. Enter that OTP to start; complete the demo trip.
7. Review earnings and Operations. Export CSV or create a demo case in the passenger safety flow while a trip is active.

To record on a supported Android phone, use the device's Screen Record option in Quick Settings. Device labels vary. Turn on Do Not Disturb and avoid recording personal notifications or sign-in credentials. Stop recording after reviewing the completed trip.

The Remotion video is an alternative scripted walkthrough with the same demo states. It does not prove native Android GPS, payments, notifications or background behavior. Those features are not connected.
